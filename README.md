## 📖 Overview

This repository contains introductory lab exercises practicing how HTML files link to CSS stylesheets located in relative subdirectories:

- **Root files:** `index.html`, `internalcss.html`, `externalcss.html`, and `external.css`.
- **Subdirectory (`S/`):** Mirrored exercises verifying relative path linking (`S/index.html`, `S/externalcss.html`, `S/external.css`).
